# DevTask PRO – Enterprise Sprint & Issue Tracker

An interactive Single-Page Application (SPA) designed for agile engineering workflows. DevTask provides full Kanban project lifecycle tracking, backlog management, and real-time velocity metrics without heavy framework dependencies.

## Key Features
- **Client-Side SPA Architecture:** Custom hash router supporting `#board`, `#backlog`, and `#analytics` views without page refreshes.
- **Native Drag-and-Drop:** Intuitive card status transitions using standard HTML5 Drag & Drop API.
- **State Management:** Reactive Store pattern with LocalStorage persistence and automated state reconciliation.
- **Search & Filter:** Multi-criteria real-time filtering across task titles, priority flags, and tags.
- **Data Portability:** Zero-dependency JSON export and import for seamless backup and restore.

## Tech Stack
- **Languages:** JavaScript (ES6+ Modules), HTML5, CSS3
- **Styling:** Tailwind CSS (Utility-First Responsive Architecture)
- **Data Layer:** Browser LocalStorage API
